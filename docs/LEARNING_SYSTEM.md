# Flutter Full-stack Learning System

## Purpose / উদ্দেশ্য

This repository is a bilingual learning system for becoming a Flutter full-stack developer. It covers Flutter, Dart, Firebase, PostgreSQL, backend APIs, testing, security, DevOps, and production projects.

এই repository-এর লক্ষ্য হলো Flutter, Dart, Firebase, PostgreSQL, backend API, testing, security, DevOps এবং production project শেখার একটি bilingual learning system তৈরি করা।

## Folder Contract / Folder-এর দায়িত্ব

- `01.Study`: theory, concepts, architecture, and technology explanations.
- `02.Practical`: runnable examples, implementation exercises, tasks, and API/property references.
- `03.Project`: complete applications and project documentation.
- `lib`: the active Flutter application source code.
- `backend`: PostgreSQL-backed API learning and implementation.
- `firebase`: Firebase rules and service configuration templates.
- `test`: automated Flutter tests.
- `docs`: repository-wide architecture, setup, and decisions.

## Required Note Contract / প্রতিটি Note-এর নিয়ম

Every substantial topic should contain:

1. Concept and explanation / ধারণা ও ব্যাখ্যা
2. Constructor, API, or property list / Constructor, API অথবা property তালিকা
3. Small code example / ছোট code example
4. Code breakdown in English and Bangla / English ও Bangla breakdown
5. Common mistakes and constraints / সাধারণ ভুল ও সীমাবদ্ধতা
6. Practical task / হাতে-কলমে task
7. Full runnable demo when applicable / প্রযোজ্য হলে সম্পূর্ণ runnable demo

## File Rules / File ব্যবহারের নিয়ম

- `.md`: bilingual theory, reference, task, architecture, and project notes.
- `.dart`: executable Dart or Flutter source only.
- `.sql`: PostgreSQL schema, migration, and seed scripts.
- `.yaml` or `.yml`: CI/CD and tool configuration.
- `.example`: safe templates without credentials.
- `.docx`: optional long-form exported study documents; Markdown remains the editable source.

Do not rename or delete existing learning material merely to satisfy this contract. Improve it incrementally.
