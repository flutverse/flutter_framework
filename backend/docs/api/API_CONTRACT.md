# API Contract / API চুক্তি

Document each endpoint with method, path, authentication, request body, success response, validation errors, and status codes.

প্রতিটি endpoint-এর method, path, authentication, request body, success response, validation error এবং status code লিখুন।

Example:

```text
GET /api/v1/health
200 { "status": "ok" }
```
