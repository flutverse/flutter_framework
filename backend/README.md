# Backend

Backend learning and implementation boundary for PostgreSQL-backed Flutter applications.

- `api/routes`: HTTP endpoint definitions.
- `api/controllers`: request and response orchestration.
- `api/services`: business operations and integrations.
- `api/middleware`: authentication, validation, logging, and error handling.
- `api/models`: backend data structures and serialization.
- `database/migrations`: versioned schema changes.
- `database/seeds`: development and test data.
- `tests`: backend behavior and integration tests.

The backend is intentionally framework-neutral until a server framework is selected.
